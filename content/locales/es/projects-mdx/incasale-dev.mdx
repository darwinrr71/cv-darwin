## Resumen

Es una aplicación web tienda online (solo frontend) llamada **"incasale"**. Permite **navegar por productos y categorías**, ver **detalle de producto**, usar **carrito** y seguir un **flujo de pago**, además de páginas como **Login**, **Novedades (NewNow)**, **Ofertas (Sale)**, **todas las categorías** y una **404**.

Está construida como una **SPA** con **React + Vite**, **Material UI**, **Javascript**, es decir, todo se maneja en el navegador y el frontend se conecta a un backend mediante **API** (hay una capa tipo **GetData.jsx** para hacer esas llamadas). El código está organizado por carpetas según su función: vistas/páginas (**views**), navegación (**navbar**), controladores de datos (**controller**) y utilidades (**functions**), con **public** para recursos. En general, la estructura es clara y modular, lo que facilita mantenimiento, reutilización y que el frontend pueda integrarse con distintos backends.
