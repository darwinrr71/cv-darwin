## Overview

It is a web application online store (frontend only) called **"incasale"**. It allows you to **browse products and categories**, view **product details**, use a **cart** and follow a **checkout flow**, as well as pages like **Login**, **News (NewNow)**, **Deals (Sale)**, **all categories** and a **404**.

It is built as a **SPA** with **React + Vite**, **Material UI**, **Javascript**, meaning everything is handled in the browser and the frontend connects to a backend via **API** (there is a layer like **GetData.jsx** to make those calls). The code is organized into folders by function: views/pages (**views**), navigation (**navbar**), data controllers (**controller**) and utilities (**functions**), with **public** for assets. In general, the structure is clear and modular, which makes maintenance and reuse easier and allows the frontend to integrate with different backends.
